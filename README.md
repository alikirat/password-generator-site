# Password Generator

A small static site that generates random passwords in the browser — no
backend, no build step, no dependencies.

## Features

- Adjustable password length (4–32 characters) via a slider
- Toggle numbers and symbols on/off (letters are always included)
- Generates two suggested passwords at a time
- Click a password to copy it to your clipboard
- Light/dark theme toggle

## Running it

Just open `index.html` in a browser, or serve the folder with any static
file server — there's nothing to install or build.

## Stack

Plain HTML, CSS, and JavaScript.
